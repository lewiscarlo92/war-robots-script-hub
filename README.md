## Project Overview

This repository acts as a unified hub dedicated to cataloging and serving War Robots mod menu scripts and assets. Instead of managing files across fragmented channels, users can inspect, structure, and retrieve all relevant materials through an accessible web interface.

Built around a clean catalog framework, the project prioritizes straightforward navigation and standardized folder grouping. New entries are deployed alongside web releases to maintain an up-to-date catalog of resources.

1. Clone or pull the repository locally:
   - `git clone https://github.com/lewiscarlo92/war-robots-script-hub.git
2. Navigate to the project root:
   - `cd ModMenu`
3. Launch the directory using any HTTP server or web browser.
4. Categorize new scripts into their designated subdirectories to maintain structure.

- `modmenu/`
